KAIWA SUITE in Google Gemini / KAIWA SUITE w Google Gemini

From the download to a first test in Gemini. Draft, untested in Gemini. Od pobrania do pierwszego testu w Gemini. Wersja robocza, nieprzetestowana w Gemini.

  1. Download Pobierz

    This is the bundle for Google Gemini. To pakiet dla Google Gemini.

    Loading… / ładowanie…

  2. Unpack Rozpakuj

    Unpack the ZIP file into a folder of your choice. Windows: right-click the file, then “Extract all”. Mac: double-click the file. You get one folder named KAIWA-SUITE-gemini. All paths on this page start in that folder. Rozpakuj plik ZIP do wybranego folderu. Windows: prawy przycisk, „Wyodrębnij wszystko”. Mac: dwukrotne kliknięcie. Powstaje jeden folder KAIWA-SUITE-gemini. Wszystkie ścieżki na tej stronie zaczynają się w tym folderze.

  3. Choose a route and set it up Wybierz drogę i skonfiguruj

    You need a Google account with access to Gemini. Account types and all menu names below are unverified. Potrzebujesz konta Google z dostępem do Gemini. Rodzaje kont i wszystkie nazwy menu poniżej są niesprawdzone.

    1. Route 1, chat with an attachment (no setup, untested). Attach 2-agents/gemini/setup-dialog.md to a new Gemini chat and write “start”. The assistant guides you through the modules. Droga 1, czat z załącznikiem (bez konfiguracji, nieprzetestowana). Dołącz 2-agents/gemini/setup-dialog.md do nowego czatu Gemini i napisz „start”.
    2. Route 2, Skill or Gem (persistent). Personal account 18+: open “Customize / Skills”, choose “Create” or “Upload” and create the Skills from the folders stream, map, analysis, sources in 2-agents/gemini/. Google Workspace education or work account where Gems are active: “Explore Gems”, “New Gem”, paste name, description and instructions from a module folder. Droga 2, Skill lub Gem (stała). Konto prywatne 18+: „Customize / Skills”, „Create” albo „Upload”, skille z folderów stream, map, analysis, sources w 2-agents/gemini/. Konto Workspace: „Explore Gems”, „New Gem”, wklej nazwę, opis i instrukcje z folderu modułu.
    3. Routes 3 (Google Drive folder) and 4 (scripts on your computer, no AI) are in the full guide. Drogi 3 (folder Google Drive) i 4 (skrypty na komputerze, bez AI) są w pełnej instrukcji.

    If Gemini lets you set an icon, use design/logo/kaiwa-icon-192.png (not checked in Gemini). Jeśli Gemini pozwala ustawić ikonę, użyj design/logo/kaiwa-icon-192.png (nie sprawdzono w Gemini).

  4. First test Pierwszy test

    1. Open the Skill or Gem (or the chat with the attachment) and write “start”. Otwórz Skill lub Gem (albo czat z załącznikiem) i napisz „start”.
    2. For the stream and the map Gemini should run a short Python check and print “OK”. If code execution is off in your region or tenant, it must warn you and save without hashes. It must never invent a hash. Dla strumienia i mapy Gemini powinien uruchomić krótki test w Pythonie i wypisać „OK”. Jeśli wykonywanie kodu jest wyłączone, musi ostrzec i zapisać bez skrótów. Nigdy nie może zmyślić skrótu.
    3. Enter two test sentences and write “end”. Check the topic list, the downloadable Excel file, the “Tool” line and the version footer. Wpisz dwa zdania testowe i napisz „end”. Sprawdź listę tematów, plik Excel do pobrania, wiersz „Narzędzie” i stopkę z wersją.

  5. Known limits Znane ograniczenia

    • All four modules are drafts and untested in Gemini. Wszystkie cztery moduły są robocze i nieprzetestowane w Gemini.
    • In some regions (including parts of the EEA) and in managed Workspace tenants Skills, Drive extensions or code execution may be switched off (unverified). Use Route 1 or the scripts. W niektórych regionach i w zarządzanych tenantach Workspace Skille, rozszerzenia Drive albo wykonywanie kodu mogą być wyłączone (niesprawdzone). Użyj Drogi 1 albo skryptów.
    • Files that the code interpreter creates must be downloaded from the chat answer by hand (unverified). Pliki z interpretera kodu trzeba pobrać z odpowiedzi w czacie ręcznie (niesprawdzone).
    • A hash shows that the text in the file did not change after it was recorded. It does not show that the model copied your words exactly. Read the file once after each session. Skrót pokazuje, że tekst w pliku nie zmienił się po zapisie. Nie pokazuje, że model przepisał dokładnie. Przeczytaj plik po każdej sesji.
    • End a recording after twenty entries. Zakończ zapis po dwudziestu wpisach.
