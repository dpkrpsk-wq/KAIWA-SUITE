KAIWA SUITE in Microsoft 365 Copilot / KAIWA SUITE w Microsoft 365 Copilot

From the download to a running agent in Copilot Chat in six steps. Draft, untested in most parts. Od pobrania do działającego agenta w Copilot Chat w sześciu krokach. Wersja robocza, w większości nieprzetestowana.

  1. Download Pobierz

    This is the bundle to unpack. You paste its texts into an agent in Copilot Chat. To pakiet do rozpakowania. Jego teksty wklejasz do agenta w Copilot Chat.

    Loading… / ładowanie…

  2. Unpack Rozpakuj

    Unpack the ZIP file into a folder of your choice. Windows: right-click the file, then “Extract all”. Mac: double-click the file. You get one folder named KAIWA-SUITE-copilot. All paths on this page start in that folder. Rozpakuj plik ZIP do wybranego folderu. Windows: prawy przycisk, „Wyodrębnij wszystko”. Mac: dwukrotne kliknięcie. Powstaje jeden folder KAIWA-SUITE-copilot. Wszystkie ścieżki na tej stronie zaczynają się w tym folderze.

  3. Create the agent Utwórz agenta

    Do not drag the ZIP file into the chat window. Copilot Chat does not accept a ZIP file as an attachment (“This file type is not supported”). Unpack it first. Nie przeciągaj pliku ZIP do okna czatu. Copilot Chat nie przyjmuje ZIP jako załącznika („Ten typ pliku nie jest obsługiwany”). Najpierw rozpakuj.

    You need a university account with access to Microsoft 365 Copilot Chat. A Copilot licence is not needed. Button names can differ with the language of the interface. Potrzebujesz konta uczelnianego z dostępem do Microsoft 365 Copilot Chat. Licencja Copilot nie jest potrzebna. Nazwy przycisków zależą od języka interfejsu.

    1. Open Copilot in the browser, choose “Agents” on the left, then “New agent”. Otwórz Copilot w przeglądarce, wybierz „Agents” po lewej, potem „New agent”.
    2. Choose the manual setup (“Configure”). Wybierz ręczną konfigurację („Configure”).
    3. Open 2-agents/copilot/stream/AGENT.md. Paste the name, the description and the starter prompts into their fields. Otwórz 2-agents/copilot/stream/AGENT.md. Wklej nazwę, opis i podpowiedzi startowe do ich pól.
    4. As the icon upload design/logo/kaiwa-icon-192.png (PNG, at most 192 × 192 pixels and 1 MB). Jako ikonę wgraj design/logo/kaiwa-icon-192.png (PNG, najwyżej 192 × 192 pikseli i 1 MB).
    5. Paste the whole content of 2-agents/copilot/stream/INSTRUCTIONS.txt into the instructions. The file is in English on purpose, because it is a prompt for the model. Wklej całą zawartość 2-agents/copilot/stream/INSTRUCTIONS.txt do instrukcji. Plik jest po angielsku celowo, bo to prompt dla modelu.
    6. Add nothing under knowledge. Save the agent (“Create”). Nie dodawaj nic w wiedzy. Zapisz agenta („Create”).
    7. Do the same for the three other agents from the folders map, analysis and sources in 2-agents/copilot/. Zrób to samo dla trzech pozostałych agentów z folderów map, analysis i sources w 2-agents/copilot/.

    Other ways to upload (a skill, a plugin) are listed below the steps. Inne drogi wgrania (skill, plugin) są pod krokami.

  4. First test Pierwszy test

    1. Open the agent. Start the conversation in the field that carries the agent’s name. If the field only says “Copilot”, you are outside the agent and its rules do not apply. Otwórz agenta. Zacznij rozmowę w polu z nazwą agenta. Jeśli pole mówi tylko „Copilot”, jesteś poza agentem i jego zasady nie działają.
    2. Write “start”. The agent should show a short piece of code and the result “OK”. This suggests that it runs code. Check the file after the session, the “OK” alone proves nothing. Napisz „start”. Agent powinien pokazać krótki kod i wynik „OK”. To sugeruje, że uruchamia kod. Sprawdź plik po sesji, samo „OK” niczego nie dowodzi.
    3. Say or type two sentences, then “end” (or “koniec”). The agent shows a list of topics and the name of the Excel file. The file lands in your OneDrive in the Copilot folder (not confirmed by Microsoft). Powiedz lub wpisz dwa zdania, potem „end” (albo „koniec”). Agent pokazuje listę tematów i nazwę pliku Excel. Plik trafia do OneDrive, do folderu Copilot (Microsoft tego nie potwierdza).

  5. Known limits Znane ograniczenia

    • This is a draft. Of the four agents only the stream agent had a first test, without a record. The others are untested in this form. To wersja robocza. Z czterech agentów tylko agent strumienia miał pierwszy test, bez protokołu. Pozostali są w tej postaci nieprzetestowani.
    • The check of a context map inside the agent is not reliable: the agent may write its own code or run none and then miss a changed map. Only the check on your own computer is reliable: python tools/context.py sprawdz <map file>. Sprawdzenie mapy w agencie nie jest pewne: agent może napisać własny kod albo go nie uruchomić i przeoczyć zmianę. Pewne jest tylko sprawdzenie na własnym komputerze.
    • Copilot shows suggestions under its replies. They do not come from the package. Do not click them during a recording, the text would count as your entry. Copilot pokazuje podpowiedzi pod odpowiedziami. Nie pochodzą z pakietu. Nie klikaj ich podczas zapisu, tekst zostałby wpisem.
    • An Excel file from Copilot carries the full name of the account owner in its properties (author, last modified by). Check it before you share the file. Plik Excel z Copilot ma we właściwościach imię i nazwisko właściciela konta. Sprawdź to, zanim go komuś przekażesz.
    • Copilot Chat without a licence has usage limits. Microsoft gives no numbers. A long session is less reliable: end it after twenty entries. Copilot Chat bez licencji ma limity użycia. Microsoft nie podaje liczb. Długa sesja jest mniej pewna: zakończ ją po dwudziestu wpisach.
