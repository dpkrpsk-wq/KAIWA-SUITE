KAIWA SUITE in Claude / KAIWA SUITE w Claude

From the download to projects in claude.ai or skills in Claude Code. Draft, untested in Claude. Od pobrania do projektów w claude.ai albo skilli w Claude Code. Wersja robocza, nieprzetestowana w Claude.

  1. Download Pobierz

    This is the bundle for Claude: projects for claude.ai and skills for Claude Code. To pakiet dla Claude: projekty dla claude.ai i skille dla Claude Code.

    Loading… / ładowanie…

  2. Unpack Rozpakuj

    Unpack the ZIP file into a folder of your choice. Windows: right-click the file, then “Extract all”. Mac: double-click the file. You get one folder named KAIWA-SUITE-claude. All paths on this page start in that folder. Rozpakuj plik ZIP do wybranego folderu. Windows: prawy przycisk, „Wyodrębnij wszystko”. Mac: dwukrotne kliknięcie. Powstaje jeden folder KAIWA-SUITE-claude. Wszystkie ścieżki na tej stronie zaczynają się w tym folderze.

  3. Choose a way and set it up Wybierz drogę i skonfiguruj

    Way A needs only a browser and suits most people. Way B is for people who already use Claude Code, a program that runs Claude in a terminal on your computer. Droga A wymaga tylko przeglądarki i pasuje większości osób. Droga B jest dla osób, które już używają Claude Code, programu uruchamiającego Claude w terminalu.

    Way A: projects in claude.ai / droga A: projekty w claude.ai

    You need a Claude account. The setting “Code execution and file creation” must be on (Settings, Capabilities), otherwise the Excel files cannot be created. Potrzebujesz konta Claude. Ustawienie „Code execution and file creation” musi być włączone (Settings, Capabilities), inaczej nie powstaną pliki Excel.

    1. In claude.ai create a new project and give it the name from 2-agents/claude/stream/PROJECT.md (the desktop app should offer the same, unverified). W claude.ai utwórz nowy projekt i nadaj mu nazwę z 2-agents/claude/stream/PROJECT.md (aplikacja desktop powinna oferować to samo, niesprawdzone).
    2. Choose “Set project instructions” (button name unverified) and paste the whole content of INSTRUCTIONS.txt from the same folder. Wybierz „Set project instructions” (nazwa niesprawdzona) i wklej całą zawartość INSTRUCTIONS.txt z tego samego folderu.
    3. Add the files listed in files.txt to the project knowledge. Dodaj pliki z files.txt do wiedzy projektu.
    4. Start a new chat in the project with the first message from PROJECT.md. Repeat for map, analysis and sources. Rozpocznij nowy czat pierwszą wiadomością z PROJECT.md. Powtórz dla map, analysis i sources.

    Way B: skills in Claude Code / droga B: skille w Claude Code

    1. Open a terminal in the unpacked folder (the one with README.md). You also need Python 3.8 or newer and pip install openpyxl. Otwórz terminal w rozpakowanym folderze (z README.md). Potrzebujesz też Pythona 3.8 lub nowszego i pip install openpyxl.
    2. Copy the four folders from 2-agents/claude/code/ into .claude/skills/ of that folder, so that .claude/skills/kaiwa-stream/SKILL.md exists. A folder whose name starts with a dot may be hidden in your file manager. Skopiuj cztery foldery z 2-agents/claude/code/ do .claude/skills/ tego folderu, tak aby istniał .claude/skills/kaiwa-stream/SKILL.md.
    3. Start Claude Code in that folder and write for example /kaiwa-stream. Uruchom Claude Code w tym folderze i napisz na przykład /kaiwa-stream.

  4. First test Pierwszy test

    1. In the module “stream of consciousness” write “start”. Claude should run a short piece of Python code and show “OK”. Check the file after the session, the “OK” alone proves nothing. W module „strumień świadomości” napisz „start”. Claude powinien uruchomić krótki kod w Pythonie i pokazać „OK”. Sprawdź plik po sesji.
    2. Enter two test sentences, then write “koniec” (end). Check the file dictation-YYYY-MM-DD-HHMM.xlsx and its sheets “entries”, “register” and “tool”. Wpisz dwa zdania testowe, potem „koniec”. Sprawdź plik dictation-RRRR-MM-DD-GGMM.xlsx i jego arkusze.

  5. Known limits Znane ograniczenia

    • All modules are drafts and untested in Claude. The skills are written for Claude Code, in claude.ai use the projects. Wszystkie moduły są robocze i nieprzetestowane w Claude. Skille są dla Claude Code, w claude.ai używaj projektów.
    • Download files that Claude creates in a chat right away (unverified that they stay). Pobieraj pliki od razu (niesprawdzone, czy zostają).
    • A hash shows that the text in the file did not change after it was recorded. It does not show that the model copied your words exactly. Skrót pokazuje, że tekst w pliku nie zmienił się po zapisie. Nie pokazuje, że model przepisał dokładnie.
    • What Claude remembers from earlier chats is no proof of provenance. To, co Claude pamięta z wcześniejszych czatów, nie dowodzi pochodzenia.
