KAIWA SUITE in ChatGPT / KAIWA SUITE w ChatGPT

Three ways on a ChatGPT Go account: one plugin for every chat, a project kit for topic projects, or four projects. Tried only in part, see Tested state. This step list is for the four projects. Trzy drogi na koncie ChatGPT Go: jedna wtyczka w każdym czacie, Projekt-Set dla projektów tematycznych albo cztery projekty. Wypróbowane tylko częściowo, zobacz stan testów. Ta lista kroków dotyczy czterech projektów.

  1. Download Pobierz

    This is the bundle for the four projects. You unpack it, it is not a plugin. The plugin for every chat is a different ZIP, see Plugin for every chat. To pakiet dla czterech projektów. Rozpakowujesz go, to nie jest wtyczka. Wtyczka do każdego czatu to inny ZIP, zobacz wtyczka w każdym czacie.

    Loading… / ładowanie…

  2. Unpack Rozpakuj

    Unpack the ZIP file into a folder of your choice. Windows: right-click the file, then “Extract all”. Mac: double-click the file. You get one folder named KAIWA-SUITE-chatgpt. All paths on this page start in that folder. Rozpakuj plik ZIP do wybranego folderu. Windows: prawy przycisk, „Wyodrębnij wszystko”. Mac: dwukrotne kliknięcie. Powstaje jeden folder KAIWA-SUITE-chatgpt. Wszystkie ścieżki na tej stronie zaczynają się w tym folderze.

  3. Way 3: create the four projects Droga 3: utwórz cztery projekty

    You need a ChatGPT Go account with Projects. Way 1 (plugin) and way 2 (project kit) are in the section Plugin for every chat. Each module is one project: stream of consciousness, context map, analysis, sources. Each folder in 2-agents/chatgpt/ holds PROJECT.md (name, description, first message), INSTRUCTIONS.txt and files.txt. Potrzebujesz konta ChatGPT Go z Projects. Drogi 1 (wtyczka) i 2 (Projekt-Set) są w sekcji wtyczka w każdym czacie. Każdy moduł to jeden projekt. Każdy folder w 2-agents/chatgpt/ ma PROJECT.md (nazwa, opis, pierwsza wiadomość), INSTRUCTIONS.txt i files.txt.

    1. In ChatGPT create a new project and give it the name from PROJECT.md. W ChatGPT utwórz nowy projekt i nadaj mu nazwę z PROJECT.md.
    2. In the project menu choose “Project settings” and paste the whole content of INSTRUCTIONS.txt into the instructions. The stream instructions are in English on purpose, because they are a prompt for the model. W menu projektu wybierz „Project settings” i wklej całą zawartość INSTRUCTIONS.txt do instrukcji. Instrukcje strumienia są po angielsku celowo, bo to prompt dla modelu.
    3. Add the files listed in files.txt to the project. Each list has at most 10 files, so one upload is enough. Dodaj do projektu pliki z listy files.txt. Każda lista ma najwyżej 10 plików, wystarczy jedno wgranie.
    4. Start a new chat in the project with the first message from PROJECT.md. Rozpocznij nowy czat w projekcie pierwszą wiadomością z PROJECT.md.
    5. Repeat for the three other modules. Powtórz dla trzech pozostałych modułów.

    Whether a limit for the length of the instructions exists is unverified. Our instructions have at most about 7,500 characters. Czy istnieje limit długości instrukcji, jest niesprawdzone. Nasze instrukcje mają najwyżej około 7500 znaków.

  4. First test Pierwszy test

    1. In the project “stream of consciousness” write “start”. The agent should run a short piece of Python code and show “OK”. Check the file after the session, the “OK” alone proves nothing. W projekcie „strumień świadomości” napisz „start”. Agent powinien uruchomić krótki kod w Pythonie i pokazać „OK”. Sprawdź plik po sesji, samo „OK” niczego nie dowodzi.
    2. Enter two test sentences, then write “koniec” (end). Download the file dictation-YYYY-MM-DD-HHMM.xlsx and check the sheets “entries”, “register” and “tool”. Wpisz dwa zdania testowe, potem „koniec”. Pobierz plik dictation-RRRR-MM-DD-GGMM.xlsx i sprawdź arkusze „entries”, „register” i „tool”.
    3. In the project “analysis” attach a file and write “start”. ChatGPT should show a start menu first and analyse nothing before you choose. W projekcie „analiza” dołącz plik i napisz „start”. ChatGPT powinien najpierw pokazać menu startowe i niczego nie analizować przed twoim wyborem.

  5. Known limits Znane ograniczenia

    • Tried only in part, see Tested state. Everything not named there is untested in ChatGPT. Wypróbowane tylko częściowo, zobacz stan testów. Wszystko, czego tam nie wymieniono, jest nieprzetestowane w ChatGPT.
    • Download the files the agent creates right away. Do not assume they stay available after the chat ends (unverified). Pobieraj pliki od razu. Nie zakładaj, że zostaną po zakończeniu czatu (niesprawdzone).
    • For the context map agree at the start of each session which map file applies and attach it to the chat. Dla mapy kontekstu na początku sesji ustal, który plik mapy obowiązuje, i dołącz go do czatu.
    • A hash shows that the text in the file did not change after it was recorded. It does not show that the model copied your words exactly. Skrót pokazuje, że tekst w pliku nie zmienił się po zapisie. Nie pokazuje, że model przepisał dokładnie.
    • Earlier chats of a project are no proof of provenance. Provenance stands only in the columns of the map file. Wcześniejsze czaty projektu nie dowodzą pochodzenia. Pochodzenie stoi tylko w kolumnach pliku mapy.

Project kit ZIP / ZIP z Projekt-Setem

For every topic project: the project instructions, the registers, the Word template and the manual. Same files in each project, own state in each. Do każdego projektu tematycznego: instrukcje projektu, rejestry, szablon Word i instrukcja bez AI. Te same pliki w każdym projekcie, własny stan w każdym.

Project kit: unpack the ZIP. For each new topic project paste INSTRUCTIONS.txt into the project settings and upload registers.xlsx, kaiwa-template.docx and README.pl.md in one go. ChatGPT does not change project files, so download the new map or register after a chat and replace the project file by hand. A second project gets the same files and keeps its own state. Projekt-Set: rozpakuj ZIP. Do każdego nowego projektu tematycznego wklej INSTRUCTIONS.txt do ustawień projektu i wgraj jednym wgraniem registers.xlsx, kaiwa-template.docx i README.pl.md. ChatGPT nie zmienia plików projektu, więc po rozmowie pobierz nową mapę albo rejestr i podmień plik w projekcie ręcznie. Drugi projekt dostaje te same pliki i ma własny stan.

Install: “Plugins” > “Hinzufügen” (Add) > “Plugin-Archiv hochladen” (Upload plugin archive), then choose the ZIP without unpacking it. The labels are from the German interface of 24 November 2026. If a plugin “kaiwa-suite” with a higher version number is already installed, delete it first, otherwise the upload is refused. Instalacja: „Plugins” > „Hinzufügen” (Dodaj) > „Plugin-Archiv hochladen” (Prześlij archiwum wtyczki), potem wybierz ZIP bez rozpakowywania. Nazwy pochodzą z niemieckiego interfejsu z 24.11.2026. Jeśli wtyczka „kaiwa-suite” z wyższym numerem wersji jest już zainstalowana, usuń ją najpierw, inaczej wgranie zostanie odrzucone.

Use one KAIWA module per chat. The plugin runs no scripts of the package, Excel files and hashes come from code that ChatGPT runs itself, so check the files. Używaj jednego modułu KAIWA na czat. Wtyczka nie uruchamia skryptów pakietu, pliki Excel i skróty pochodzą z kodu, który uruchamia sam ChatGPT, więc sprawdzaj pliki.
